# Runbook: EC2 Instance Down

## Cause

The instance may be stopped, terminated, unhealthy, or unreachable because of network or system issues.

## Steps

* [ ] Check the EC2 instance state in the AWS Console.
* [ ] Check system and instance status checks.
* [ ] Verify security group and network connectivity.
* [ ] Check CloudWatch logs and recent instance events.
* [ ] Restart the instance if required and verify application health.
